Porting needs the TensorRT 8.2 binding-index API rewritten for TRT 10 (removed, not deprecated), engines rebuilt on the board, the JetPack 4 `bufapi-version=1` CSI path dropped, the new `nvstreammux`, NvDCF instead of the DS 6.0 IOU config, and the dashboard on Python 3.12.
