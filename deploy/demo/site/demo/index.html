Face matching

in use: cosine ≥ 0.50
Both compare the same face templates and always pick the same closest person; only the pass rule differs. They relate as L2 = √(2 − 2 × cosine): cosine 0.50 is L2 1.00, L2 0.95 is cosine 0.55. Higher cosine or lower L2 means stricter: fewer false matches, more faces left Unknown.
